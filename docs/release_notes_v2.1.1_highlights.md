# v2.1.1 — Dependency floor bumps unblocked by v2.1.0

## English

**Highlights**

- Bumped `requests`, `mypy`, and `pytest` to their current minimum floors —
  the same three updates that were blocked on Python 3.9 support, now
  unblocked by v2.1.0 dropping it.
- No public API changed.

## 한국어

**주요 변경사항**

- `requests`, `mypy`, `pytest`의 최소 버전을 올렸습니다 — v2.1.0에서 Python
  3.9 지원을 종료하면서 막혀있던 업데이트 3건이 풀린 것입니다.
- 공개 API 변경 없음.

## 繁體中文

**重點更新**

- 提升了 `requests`、`mypy`、`pytest` 的最低版本 —— 這正是先前因 Python 3.9
  支援而卡住的三項更新，隨著 v2.1.0 移除 3.9 支援而得以恢復。
- 沒有公開 API 變更。
