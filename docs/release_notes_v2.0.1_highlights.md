# v2.0.1 — Lightweight multilingual README

## English

**Highlights**

- No SDK behaviour changed — packaged-metadata-only release.
- `README.md` (the PyPI project description) trimmed from ~15.7 KB to
  ~4.3 KB: each language block now carries only the essentials, with
  developer-level detail pointing to the [documentation site](https://dennis5882.github.io/MIDAS-API-NX-SDK/)
  instead of being duplicated inline.
- Added a 简体中文 (Simplified Chinese) block alongside English, 한국어, and
  繁體中文.

## 한국어

**주요 변경사항**

- SDK 동작 변경 없음 — 패키지 메타데이터(README)만 변경된 릴리즈입니다.
- PyPI 프로젝트 설명으로 쓰이는 `README.md`를 약 15.7KB에서 4.3KB로
  축소했습니다. 각 언어 블록은 핵심 내용만 담고, 개발자용 상세 내용은
  [문서 사이트](https://dennis5882.github.io/MIDAS-API-NX-SDK/)로 연결합니다.
- 기존 영어/한국어/繁體中文에 简体中文 블록을 추가했습니다.

## 繁體中文

**重點更新**

- SDK 行為未變更 —— 僅為套件中繼資料（README）異動的版本。
- 作為 PyPI 專案說明的 `README.md` 從約 15.7KB 精簡至 4.3KB：各語言區塊
  僅保留核心內容，開發者層級的細節改為連結至
  [文件網站](https://dennis5882.github.io/MIDAS-API-NX-SDK/)，不再重複收錄。
- 在既有的英文／한국어／繁體中文之外，新增了簡體中文區塊。
